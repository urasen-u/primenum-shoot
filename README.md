操作方法

A,Dキー:発射方向の操作

左右キー:自機の移動

上下キー:発射する数字の選択

Spaceキー:発射

ゲーム概要

襲ってくる敵に書かれた数字の約数を当てて敵を倒しましょう。

約数を当てると、敵の数字はその数で割った数になります。

敵の数字が1に出来れば、その敵を倒すことが出来ます。

しかし、約数でない数を当ててしまうと、敵の数字が当てた数を掛けた数になってしまい、その数がしばらく使えなくなってしまいます。

敵が画面下に到達すると、ダメージを受けてしまい、右上に表示された体力がなくなるとゲームオーバーです。

左上に表示された敵の数がが0になればクリアです！

[技術的背景]

・ボス戦の演出
特定の条件を満たして通常ステージをクリアすると、ボスバトルに突入します。
その際、警告音と共に画面が振動し、同時に画面が少しずつ赤くなっていきます。
これにより、ボスの襲来の緊張感を演出することに成功しました。

・攻撃ヒット時の演出
敵に攻撃がヒットした際、攻撃が成功すれば敵が少しノックバックし、反対に攻撃が吸収されると敵が上下に伸縮します。
これにより、攻撃の成功失敗をより直感的に表すことに成功しました。
